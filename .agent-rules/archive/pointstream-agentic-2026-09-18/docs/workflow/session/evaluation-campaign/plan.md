## Search design and budgets

Reuse before running: E01 checks existing indexes, folders, manifests and decodes;
every later card cites its own reuse decision. A repaired implementation does not
upgrade an old artifact automatically. Before reading headline metrics, state
plausible two-sided bounds and controls. Use the smallest probe answering a
specific decision, not a full Cartesian grid.

Start with low spatial resolution and frame rate for learning/debugging. Default
screen endpoints, finalized against source metadata by E01: short edge 360 pixels
versus native resolution (no upsampling); 12 fps versus native fps (never create
extra source frames). If source is below either low endpoint choose a genuinely
lower supported value. Preserve aspect ratio and record padding/alignment. Include
both mixed resolution/fps corners for finalists to separate their effects.
For colour, screen supported high-fidelity RGB/4:4:4 versus YUV4:2:0 paths with
explicit matrix, range, transfer and bit depth. Categories are not numeric high/low
values: select two valid paths and record unsupported cases. Screen additional
axes only with a mechanism: short/long duration, refresh/GOP/lookahead, spatial
filter, bit depth, precision, reference cadence, QP and model resource settings.
Never silently reinterpret incompatible native formats as equal inputs.

Within a batch change one factor against a shared low-cost baseline, then check
consequential interactions (resolution × fps, representation × removal, predictor
× residual). Use at least two coarse rate points for screening; expand finalists
to enough actual overlapping points for valid RD comparison, normally four.
High-resolution/native-fps evaluation is a second batch for promising candidates,
with a bounded check of a low-resolution loser where scaling could reverse the
ranking. Finish with one or two intermediate operating points near the measured
feasibility boundary, e.g. 720p/1080p where sources support them. Do not retrain
every model from scratch at every grid cell; verify transfer and selectively
fine-tune finalists, preserving crop-size/context constraints.

Default first probe per new axis: at most six candidate configurations and 30
minutes execution including scoring, as in experiment-design.md. Slow native
anchors may not fit: estimate one case, return a costed card before extending.
