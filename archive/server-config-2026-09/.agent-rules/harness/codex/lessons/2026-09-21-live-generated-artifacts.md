# 2026-09-21 — live generated artifacts and hook trust

Codex role TOMLs and `$CODEX_HOME/AGENTS.md` are install-time outputs, not
the source of truth. After a harness layout move, the live hook symlink and
all generated role files can be stale even when the repository is clean.
Run a Codex-only installer check and compare generated bytes with the
renderer before claiming the roles load. The hook manifest also needs a
real JSON parse: a missing root brace passed source inspection but blocked
`/hooks` trust.

After repairing the manifest, `/hooks` showed five changed hooks and
`Trust all` succeeded. A fresh native startup logged a real SessionStart
payload and context. Direct live payloads then confirmed PreToolUse deny,
UserPromptSubmit, PreCompact, and ordinary Stop behavior. Ordinary Stop is
not closeout; only an explicit boundary wrote the replay-safe no-lessons
receipt. Do not spawn the Astra escalation rung when quota is thin; keep
legacy config role tables until a child actually spawns, then remove them.
